# Дом у дерева — счётная книга

Книга заказов мастерской «Дом у дерева». Считает так же, как общая Google-таблица: цена ингредиента (вручную, аукцион или свой крафт), себестоимость по рецепту, наценка, скидка и округление итога вверх до гроша. Закупка берётся по целым крафтам, без платы за станок.

В заказ можно вписать название так, как оно написано в игре, или открыть список изделий стрелкой в строке. У столярных изделий в списке показаны и строка книги, и имя из игры: «деревенский стул» — это стул 3 уровня, «деревенский табурет» — стул 2 уровня, «фонарь» — нарядный фонарь 5 уровня. Если навести курсор на поле, рядом появляется подсказка, что туда писать.

Отдельный файл `public/dom-u-dereva-mebel.xlsx` — список мебели на 150 строк. У каждой строки в столбце «Статус» свой список «Сделано» или «Не сделано»; пустые строки внизу можно заполнить самим. Это не вкладка старой книги заказов. Если таблица уже открыта в Google, выберите «Файл → Импортировать → Заменить текущий лист». Пересобрать файл: `python3 scripts/build-furniture-list.py`. Книга подставляет строку рецепта из общей таблицы: «Двуспальная деревенская кровать» считается как «Простая двуспальная кровать (декор)».

Аукцион при открытии читается из общей Google-таблицы: там скрипт обновляет его раз в день. Если таблица не открылась, остаётся снимок, вшитый в книгу. Свои цены и заказы остаются в этом браузере. Файл «Сохранить книгу» переносит их на другой компьютер.

## Запуск

```bash
npm install
npx next dev -p 43123
```

Откройте http://127.0.0.1:43123

## Публичная страница

Сборка — обычный статический сайт, как у примера на GitHub Pages. В репозитории уже есть действие `.github/workflows/pages.yml`: после каждого отправления в `main` оно публикует книгу.

Репозиторий должен быть публичным. В настройках GitHub откройте Settings → Pages и выберите источник GitHub Actions. Адрес будет таким: `https://<имя>.github.io/<репозиторий>/`.
